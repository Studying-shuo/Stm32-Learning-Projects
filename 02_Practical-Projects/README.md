# 实战项目

这里收录可以独立展示的综合项目。每个项目应将源码放在 `Project/`（或已有工程目录）中，并按需新增 `Hardware/`、`Images/` 与 `Docs/`。

| 项目 | 状态 | 重点 |
| --- | --- | --- |
| [`01_Traffic-Light`](01_Traffic-Light/README.md) | 已归档 | GPIO、按键、延时与多灯控制 |

新项目请采用数字前缀保证展示顺序，例如 `02_Digital-Clock`、`03_Temperature-Monitor`。说明文档可从 [`PROJECT_TEMPLATE.md`](../docs/PROJECT_TEMPLATE.md) 复制。
