# STM32 红绿灯控制器

基于 STM32F103C8T6 的三色 LED 时序控制练习。项目通过 GPIO 驱动红、绿、黄三盏 LED，并使用按键读取验证输入检测与消抖流程。

## 功能

- 红灯亮 5 秒、绿灯亮 5 秒、黄灯亮 2 秒，随后循环执行。
- 三种状态切换时先关闭其余两盏灯。
- 读取 PB1 按键；按下后调用 `Light_Blow()` 将三盏灯关闭一次，随后主循环重新开始时序。

## 硬件连接

| 功能 | STM32F103C8T6 引脚 | 程序中的状态 |
| --- | --- | --- |
| 红灯 | PA0 | 高电平点亮 |
| 绿灯 | PA1 | 高电平点亮 |
| 黄灯 | PA2 | 高电平点亮 |
| 按键 | PB1 | 上拉输入，低电平有效 |

> LED 与按键的实际接线应与上述逻辑一致；首次上电前请确认限流电阻、共地和供电电压。

## 开发环境

- MCU：STM32F103C8T6
- 语言：C
- 外设库：STM32F10x 标准外设库
- 工程工具：Keil MDK

## 工程位置与构建

Keil 工程位于 [`3-1 Traffic_lights/Projsct.uvprojx`](3-1%20Traffic_lights/Projsct.uvprojx)。使用 Keil MDK 打开该文件，选择与开发板匹配的下载器配置后编译、下载。

关键业务代码位于：

- [`User/main.c`](3-1%20Traffic_lights/User/main.c)：主循环与按键处理。
- [`Hardware/LED.c`](3-1%20Traffic_lights/Hardware/LED.c)：三色灯初始化和时序函数。
- [`Hardware/Key.c`](3-1%20Traffic_lights/Hardware/Key.c)：按键初始化、检测和软件消抖。

## 学习要点

- APB2 外设时钟使能与 GPIO 模式配置。
- 多个 GPIO 的协同输出与状态切换。
- 上拉输入、低电平有效按键和软件消抖。
- 用阻塞延时实现简单状态机，以及它对按键响应性的限制。
