# 学习笔记

用于记录“为什么这样配置”，而不只是粘贴寄存器或库函数。每篇笔记建议包含：概念、关键配置、最小示例、常见错误和个人总结。

## 建议顺序

1. `01_GPIO.md`：时钟使能、输入输出模式、推挽与开漏。
2. `02_EXTI.md`：外部中断、NVIC 与按键消抖。
3. `03_Timer_PWM.md`：定时器时基、PWM 频率与占空比。
4. `04_ADC.md`：采样、参考电压与数据处理。
5. `05_USART.md`：串口配置、收发流程与调试。
6. `06_I2C_SPI.md`：总线时序与传感器通信。

笔记与工程互相链接：工程 README 链接到对应原理笔记；笔记链接到可运行的最小工程。
