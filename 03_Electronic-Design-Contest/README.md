# 电子设计竞赛

本目录面向电赛训练和正式参赛项目。每个赛题或训练题建议采用以下轻量结构：

```text
项目名/
├── README.md              # 题目、目标、进度与最终结果
├── Hardware/              # 原理图、PCB、元件清单
├── Software/              # 可构建的源代码与工程配置
├── Docs/                  # 方案、报告、测试记录
└── Images/                # 实物与测试截图
```

记录方案取舍、测试数据和未解决问题，比只保存最终代码更能体现工程过程。
